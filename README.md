Portafolio personal de Alan Cruz, Desarrollador Full Stack Java Jr., enfocado en desarrollo de software, tecnología, robótica y análisis de datos.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git y GitHub

```text
PortafolioWeb/
```

## Páginas

- `index.html`: portafolio personal, trayectoria y proyectos.
- `ixtlan.html`: proyecto Ixtlán STEAMex.

## Ejecución local

1. Clonar o descargar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar `index.html` con la extensión Live Server.

## Publicación

El sitio estará disponible mediante GitHub Pages una vez configurada su publicación.
